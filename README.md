# Tesi-LLM-Cybersecurity
Impatto degli LLM sugli attacchi informatici moderni: dalla manipolazione cyber-sociale all'identificazione di pattern per la difesa
Tesi triennale in Informatica, Università degli Studi di Bari Aldo Moro (2025/2026).
## Di cosa parla
Analisi dell'uso offensivo e difensivo dell'AI generativa,
mappato sulle fasi della cyber kill chain.
## Parte sperimentale
Due scenari testati con Claude e Gemini, a parità di prompt:
- **Quishing**: generazione di QR code malevoli e risposta dei modelli ai filtri di sicurezza
- **Exploit**: sfruttamento di Ghostcat (CVE-2020-1938) su Apache Tomcat,
  in ambiente TryHackMe con Metasploit

Per ciascuno scenario è stata valutata anche la parte difensiva.
